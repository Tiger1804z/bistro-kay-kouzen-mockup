17. UX / RESPONSIVE
==================================================

Design desktop first at approximately 1440px width.

But all layouts must be easily adaptable to mobile.

Avoid complicated overlaps that become impossible to reproduce in code.

Use:
- clear sections
- reusable cards
- consistent spacing
- sensible grid
- reusable button styles
- reusable heading styles
- reusable glow effects

Create a consistent design system.

Suggested spacing rhythm:
large generous sections approximately 100–140px vertical desktop.

Do not make the homepage unnecessarily long.

Each section should earn its place.

==================================================
18. INTERACTION CONCEPTS
==================================================

The final coded site will likely use subtle motion.

Design with these future interactions in mind:

- fade/reveal on scroll
- slight image scale on hover
- CTA glow intensifies slightly on hover
- event cards lift subtly
- navbar transitions into blurred background
- stars move extremely slowly/parallax
- image masks reveal on scroll

DO NOT make animation essential to understanding the layout.

==================================================
20. IMPORTANT FOR DEVELOPMENT
==================================================

This design will later be reproduced in code by a developer.

Therefore:

- create clean reusable components
- maintain consistent spacing
- avoid impossible shapes
- avoid excessive absolute positioning
- make image areas clear
- use normal web layout logic
- maintain readable typography
- keep visual effects reproducible with CSS
- avoid effects that require complex WebGL
- use components that can later map naturally to React/Next.js

The result should look impressive enough to present directly to the restaurant owner as a professional website concept.
